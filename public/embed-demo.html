Embed Widget Demo

This page demonstrates all available embed modes and configuration options. Replace YOUR_CHATBOT_ID with your actual chatbot ID.

<!-- Popup mode (default) --> <script src="https://drop-bot-ebon.vercel.app/embed/YOUR_CHATBOT_ID/widget"></script>

Configuration Options

Customize the widget via data-* attributes, URL query params, or the window.DropBotConfig object.

<!-- Via data attributes --> <script src="https://.../embed/CHATBOT_ID/widget" data-mode="slide-in" data-position="left" data-button-color="#7c3aed" data-button-size="56" data-title="Ask us anything" data-width="420" data-height="640" data-auto-open="true" data-auto-open-delay="5000" data-api-url="https://drop-bot-ebon.vercel.app" ></script> <!-- Via global config object --> <script> window.DropBotConfig = { chatbotId: "CHATBOT_ID", mode: "popup", position: "right", buttonColor: "#2563eb", buttonIcon: "chat", // "chat" | "message" | "help" | custom SVG autoOpen: true, autoOpenDelay: 3000, title: "Support", apiUrl: "https://drop-bot-ebon.vercel.app", // Callback hooks onOpen: function() { console.log("Chat opened") }, onClose: function() { console.log("Chat closed") }, onMessage: function(msg) { console.log("Message:", msg) }, onReady: function() { console.log("Widget ready") }, onError: function(err) { console.error("Widget error:", err) }, }; </script> <script src="https://.../embed/CHATBOT_ID/widget" async defer></script>
